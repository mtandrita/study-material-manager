# 🚀 Quick Start Guide

Get up and running with Semester Manager 2.0 in 30 seconds!

## ⚡ Ultra-Quick Start

### Option 1: Direct File (Fastest ⚡)
```bash
1. Download the repo
2. Open index.html in your browser
3. Done! ✨
```

### Option 2: Local Server (Recommended)

**Using Python:**
```bash
# Python 3.x
python -m http.server 8000

# Python 2.x
python -m SimpleHTTPServer 8000
```

**Using Node.js:**
```bash
npx http-server
```

**Using Ruby:**
```bash
ruby -run -ehttpd . -p8000
```

Then open: `http://localhost:8000`

## 🎯 First Steps

1. **Explore the Dashboard**
   - See your study stats
   - View your streak

2. **Try the Pomodoro Timer**
   - Click "Start" → Study for 25 min
   - Watch your hours tracked

3. **Add a Subject**
   - Name, Professor, Schedule, Grade
   - Upload a PDF if you have one

4. **Add a Deadline**
   - Set an important date
   - Choose deadline type

5. **Create a Goal**
   - Weekly goal with priority
   - Track your progress

## 🐛 Issues?

If something doesn't work:

1. **Clear browser cache** → Ctrl+Shift+Delete
2. **Check browser compatibility** → Use modern browser
3. **Check browser storage** → IndexedDB must be enabled
4. **Try different browser** → Test in Chrome/Firefox
